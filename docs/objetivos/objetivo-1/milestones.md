# Milestones
Definen qué quiero entregar, no cómo entregarlo. Un milestone no es "he terminado tal HU": marca el nivel de profundidad con el que se resuelve el problema en ese momento.

## Milestone 0: Modelo inicial de dominio

### Objetivo
Representar de forma coherente los conceptos mínimos del dominio necesarios.

### Qué se entrega
- Las entidades y objetos valor mínimos que representan el dominio, modelados en código y organizados según las buenas prácticas del lenguaje elegido.
- Sin lógica de negocio todavía: el objetivo es tener una estructura de datos correcta.
- Una definición del diseño del dominio (DDD) que indique claramente qué es objeto valor, qué es entidad y qué relaciones hay entre ellos.
- Documentación breve de las decisiones de modelado.


## Milestone 1: Primera flujo funcional verificable

### Objetivo
Demostrar que el modelo de dominio del milestone previo puede utilizarse para resolver de principio a fin un caso de uso simple relacionado con las historias de usuario.

### Qué se entrega
- La lógica mínima necesaria para ejecutar un caso de uso completo.
- Pruebas automatizadas del comportamiento principal.
